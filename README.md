
# Менеджер интернет-закладок

Данное веб-приложение для сохранения и организации полезных интернет-ссылок. Пользователь может добавлять ссылки на учебные материалы, статьи, документацию и другие страницы, указывать собственные описания и распределять закладки по тегам.

## Возможности

- добавление закладок с названием, URL, описанием и тегами;
- просмотр и удаление закладок;
- редактирование URL, названия, описания и тегов;
- поиск по названию;
- фильтрация по тегу;
- сортировка по времени создания;
- подсчёт количества закладок по каждому тегу.

| Компонент | Технологии |

## Архитектура проекта

Приложение состоит из двух микросервисов и базы данных MongoDB.

### 1. Основной сервис (Main Service)

Отвечает за работу с закладками:

- принимает запросы от клиентского приложения;
- выполняет операции создания, получения, изменения и удаления закладок;
- осуществляет поиск и фильтрацию;
- взаимодействует с MongoDB.

### 2. Сервис отчётов (Report Service)

Отвечает за формирование статистики:

- получает список закладок от основного сервиса по HTTP;
- обрабатывает полученные JSON-данные;
- подсчитывает количество закладок для каждого тега;
- возвращает результат в формате JSON.

Сервис отчётов не обращается к базе данных напрямую.

### 3. База данных MongoDB

Используется для хранения информации о закладках. Данные сохраняются в коллекции `bookmarks` базы данных `bookmark_db`.

Для сохранения данных между перезапусками контейнеров используется Docker Volume.

## Запуск приложения

Для запуска необходимы:

- Docker;
- Docker Compose;
- Git (для клонирования репозитория).

### 1. Клонирование репозитория

```bash
git clone <URL-репозитория>
```

Перейдите в папку проекта:

```bash
cd BookMarks_kursovaya
```

### 2. Запуск контейнеров

Выполните команду:

```bash
docker compose up -d --build
```

Docker Compose автоматически:

- создаст контейнер MongoDB;
- соберёт образ основного сервиса;
- соберёт образ сервиса отчётов;
- запустит все три контейнера;
- создаст Docker Volume для хранения данных базы данных.

### 3. Проверка работы

После запуска приложение доступно по следующим адресам:

| Компонент | Адрес |
|---|---|
| Веб-интерфейс | http://localhost:8000 |
| Swagger основного сервиса | http://localhost:8000/docs |
| Swagger сервиса отчётов | http://localhost:8001/docs |

## API основного сервиса

Базовый адрес: `http://localhost:8000`

| Метод | Эндпоинт | Описание |
|---|---|---|
| POST | `/bookmarks/` | Создание закладки |
| GET | `/bookmarks/` | Получение списка закладок |
| GET | `/bookmarks/{bookmark_id}` | Получение закладки по ID |
| PATCH | `/bookmarks/{bookmark_id}` | Изменение закладки |
| DELETE | `/bookmarks/{bookmark_id}` | Удаление закладки |

### Параметры получения списка закладок

Эндпоинт `GET /bookmarks/` поддерживает параметры:

| Параметр | Описание |
|---|---|
| `search` | Поиск по названию |
| `tag` | Фильтрация по точному совпадению тега |
| `sort` | Сортировка по дате: `asc` или `desc` |

Пример запроса:

```http
GET /bookmarks/?search=Python&tag=Учёба&sort=desc
```

### Пример JSON закладки

```json
{
    "url": "https://fastapi.tiangolo.com/",
    "title": "Документация FastAPI",
    "description": "Официальная документация FastAPI",
    "tags": [
        "Python",
        "Учёба"
    ]
}
```

Дата добавления формируется автоматически при создании закладки.

## API сервиса отчётов

Базовый адрес: `http://localhost:8001`

| Метод | Эндпоинт | Описание |
|---|---|---|
| GET | `/reports/tags` | Получение количества закладок для каждого тега |

Пример ответа:

```json
{
    "Python": 5,
    "Учёба": 3,
    "Работа": 2
}
```

## Остановка приложения

Для остановки контейнеров выполните:

```bash
docker compose down
```

Данные MongoDB сохраняются в Docker Volume и не удаляются при обычной остановке контейнеров.

**Важно:** команда `docker compose down -v` удаляет также Docker Volume с данными базы данных.

## Документация API

Для документирования API используется OpenAPI, автоматически формируемый FastAPI.

Интерактивная документация доступна через Swagger UI для обоих сервисов. С её помощью можно просматривать эндпоинты, изучать схемы запросов и ответов, а также выполнять тестовые запросы.
